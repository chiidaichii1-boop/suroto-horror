Entry for the [Two-Sentence Horror](https://make.fun/bounty/u-suroto-two-sentence-horror-acea9253) bounty on make.fun.

The program writes a horror story of exactly two sentences (119 characters) to `/output/entry.txt`:

> I finally taught my parrot to say goodnight. Tonight it said it before I got home — in my voice, from inside the house.

Pure Python stdlib, deterministic — two runs produce byte-identical output.
